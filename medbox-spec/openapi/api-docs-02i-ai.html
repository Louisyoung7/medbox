medbox · AI 洞察层（02i OpenAPI 版） (1.0.0)

Download OpenAPI specification:

medbox-spec/05_AI大模型与洞察层方案.md 的机器可读版。通用约定见 common.yaml。

硬边界（05 §0.2 / §2.4）：

  • 洞察只消费结构化数据，不落库、不自动执行；所有响应必带 disclaimer；
  • BYOK：每个老人一份 llm_config，由监护人代配 Key，后端不托管大模型；
  • 未配置 / Key 无效 / 上游失败统一 50310；无数据时不调上游，返回 code=0 的模板化提示。

保存 LLM 配置【鉴权·仅监护人 CONFIG_LLM_KEY】

model / baseUrl 必填，baseUrl 必须以 http 开头；provider 缺省 openai-compatible。 首次配置必须填 apiKey；编辑其他字段时 apiKey 留空表示沿用旧密文。 Key 加密（AES-GCM）落库，响应只回脱敏值。

同步生成洞察【鉴权·AI_INSIGHT；限流 10 次/分钟/用户】

type 缺省 COMPREHENSIVE；range 缺省为最近 14 天，跨度上限 90 天（超出 → 40001）。 时间范围内无任何结构化数据时不调上游，返回 code=0 + 模板化 content。 洞察结果不落库；上游超时（15s）/ 失败 → 50310。

bearerAuth
Request Body schema: application/json
required
elderId
required
string
type
string (InsightType)
Enum: "ADHERENCE" "ENV_CORRELATION" "TREND" "MEDICATION_SAFETY" "COMPREHENSIVE"

deviceId
string

可选；当前版本不参与洞察上下文（保留字段）

SSE 流式生成洞察【鉴权·AI_INSIGHT；限流 10 次/分钟/用户】

请求体同 /ai/insight。成功时 Content-Type: text/event-stream，逐帧 data: {json}：

  • {"type":"delta","content":"…"}
  • {"type":"done","citations":[...],"disclaimer":"…"}
  • {"type":"error","code":50310,"message":"AI 服务暂不可用，请稍后再试"}

鉴权、取 Key、拼上下文在请求线程内完成；失败按普通 JSON 错误返回（非 SSE）。
