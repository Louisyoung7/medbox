medicines

药品档案（必归属老人，无公共字典）

新建/更新药品档案【鉴权·WRITE_MEDICINE（仅 GUARDIAN）】

更新时请求体带 medicineId，创建不带（由后端生成）；药品必归属某位老人（无公共字典）： ownerElderId 创建必填（留空 → 40001），更新时传了也会被忽略（归属不可变）。 可见范围 = 我监护老人的药品（服务端按 visibleElderIds() 行级过滤）。 含药品说明、储存条件等字段（详见 06 §2.4）。

Authorizations:
bearerAuth
header Parameters
X-Request-Id
string
Example: 9f2c0f11a2b34c55d6e7f809a1b2c3d4

32 位小写十六进制（无连字符）；写方法（POST/PUT/PATCH/DELETE）自动注入，幂等去重用；GET 不注入

Request Body schema: application/json
required
medicineId
string

更新时必带；创建不传（后端生成）

name
required
string
unit
string or null
description
string or null <= 2000 characters

药品说明（监护人手动填写），AI 用药安全洞察只依据此文本

ownerElderId
string

归属老人业务 ID；创建必填，更新时忽略（归属不可变）

我的药品列表（分页、搜索）【鉴权】

可见范围 = 我监护老人的药品（行级过滤）；无 ACTIVE 监护关系时返回空分页。分页按通用约定 page/size、返回 total。

Authorizations:
bearerAuth
query Parameters
keyword
string

按名称搜索

page
integer >= 1
Default: 1

页码，从 1 起（<1 → 40001）

size
integer >= 1
Default: 20

每页条数，默认 20，通用上限 100（抓拍列表上限 200）

Responses
