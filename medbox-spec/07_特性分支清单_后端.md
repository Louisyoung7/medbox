# 07 · 特性分支清单（Java 后端）

> 每个 `- [ ]` 待办 **对应一个特性分支**，分支名见每条的 `feat/xxx`。
> **修 Bug、重构项目结构不计入本清单**（不单独开分支记账，随所在模块一起提交即可）。
> 图例：🧱 = **地基**（后续任务都依赖它）；🔧 = **功能任务**；🧭 = **判定型**（含业务规则与优先级，**动手前先出规则表给用户确认**，见 `AGENTS.md` 的 3.1）。
> **认领与引用一律用分支名**（如"对应 07 的 `feat/plan-core`"），**不要用"第 N 项"** —— 清单会重排，序号不稳定。
> 依赖列的分支必须先合并；"参考"指向 `medbox-spec/` 下的文档章节，实现前请先读对应章节。
> **依赖列只写本端分支**（同一端内的前后置）。**本分支解锁哪些小程序分支**以 `08` 各分支的依赖列为准（**那里是唯一事实源**，反向索引不再在本文维护，避免两处不一致）。
> 完成后勾选 `- [x]`，并在 PR 描述里写明"对应 07 的 `feat/xxx`"。

> **清单即实施顺序**：第一章地基 → 第二章 **P0 主干闭环** → 第三章 **P1 完善** → 第四章 **P2 改造 + 原 P1 剩余（随文档大改动跟进）** → 第五章 **P3 锦上添花（原 P2，可砍）**。
> **P0 全部做完即为可演示 MVP**；P3 整体后置，时间不够可整块砍掉，不影响主干演示。**P2 是文档 `02→8 分册` / `06→11` / 摄像头 HTTP 上报 / §3.7 减法 后的代码跟进层**，含契约级改动（摄像头上报方式、过期功能删除）与从 P1 平移下来的未做分支。
> 已按此原则**合并同类分支**：原 46 个待办（地基 8 + 功能 38）合并为 **37 个分支**（地基 8 + P0 7 + P1 12 + P2 4 + P3 6），能在同一分支写完并一起测试的都合在了一起；合并项在各条标题括号内标出原待办名。

> **路径与分支**：本清单所有代码**都在 `medbox-server/` 下**（如 `src/main/resources/application.yml` = `medbox-server/src/main/resources/application.yml`）；分支名 `feat/backend-xxx` 或 `feat/xxx`，**一个分支只改 `medbox-server/`**。文档改动（`medbox-spec/`）与代码放进**同一个 PR** 即可，**不要求同一个 commit**（按层分批提交也可以）。
>
> **构建工具约定（V1.9 起）**：后端是**单项目 Gradle 工程（Kotlin DSL，Wrapper 9.7.1）+ Spring Boot 4 + JDK 21**（编译与目标运行时均为 21，不再做 `--release 17` 降级）。常用命令：`./gradlew bootRun` 启动、`./gradlew build` 构建、`./gradlew test` 测试；IDE 直接运行 `com.medbox.server.MedboxServerApplication`。**基础包名 `com.medbox.server`**，servlet context-path 为 `/medbox`（故健康检查是 `GET /medbox/actuator/health`）。
>
> **注意 Spring Boot 4 的两个差异**：① 自带 **Jackson 3**（`com.fasterxml.jackson` → Jackson 3 的坐标与 API 有调整，写 DTO / 自定义序列化时留意）；② `spring.ai.*`（Spring AI）需按 Boot 4 对应的 Spring AI 版本引入，`feat/backend-ai-infra` 落地时对齐。
>
> **持久层框架（V1.14 定）**：**MyBatis-Plus**。地基 `feat/backend-db` 只做建表与迁移、**不引入该依赖**；各功能分支按需引入并写实体 / Mapper（`mapper/` 与 `domain/` 包已预留）。
>
> **数据库（V1.14 起）**：PostgreSQL 17（不再启用 pgvector），表由 Flyway 管理（脚本在 `src/main/resources/db/migration/`）。Boot 4 下除 `flyway-core` / `flyway-database-postgresql` 外，**还必须引 `org.springframework.boot:spring-boot-flyway`**，否则静默不迁移（详见 `medbox-server/README.md`）。
