## 1. 客户端版本与 APK 分发

> 版本信息来自后端配置 `medbox.app.*`（`version-name` / `version-code` / `apk-file-name` / `download-url` / `release-notes`），**不落库、不新增表**。发版时改配置并把 APK 放进 `medbox.app.download-dir`，或改用对象存储（填 `download-url`）。

### 1.1 `GET /app/version`（免登录）

APK 首次启动、尚未登录时就要能查最新版本，因此本接口**不走 JWT**（`AuthInterceptor` 排除 `/api/v1/app/**`）。

**判定表（`versionCode` 为客户端当前版本，即 Android manifest 的 versionCode）：**

| 输入 | 判定 | 输出 |
|------|------|------|
| 不传 `versionCode` | 无法比较（App 启动即查最新版） | `upToDate=false` |
| `versionCode >= latestVersionCode` | 已是最新 | `upToDate=true` |
| `versionCode < latestVersionCode` | 有更新 | `upToDate=false` |
| `versionCode` 为负数 | 参数非法 | 40001 |

**下载地址口径**：优先返回 `medbox.app.download-url`（对象存储 / CDN 完整 URL）；留空时按
`http://{medbox.host}:{medbox.ports.http}/medbox/app/{apkFileName}` 推导，其中 `apkFileName` 留空时按
`medbox-{version-name}.apk` 推导。

### 1.2 APK 静态下载（免登录）

`GET /medbox/app/{apkFileName}` 直接返回文件流（**不套统一响应体**），由后端把 `medbox.app.download-dir`
映射到 `/app/**`。该路径不在 `/api/v1/**` 下，不经过 `AuthInterceptor`；目录不存在 / 文件名不存在时返回 404。

> 生产建议直接使用对象存储并把 `download-url` 配成 CDN 地址，后端只负责版本检查。

### 1.3 错误码与边界（不新增码值，沿用 02_REST接口设计.md §1.2）

| 端点 | 场景 | code | HTTP |
|------|------|------|------|
| `GET /app/version` | `versionCode` 为负数 / 非整数 | 40001 | 400 |
| `GET /app/version` | 其余情况（含未登录） | 0 | 200 |
| `GET /app/{file}` | 文件不存在 | — | 404 |

### 1.4 CORS

H5 仅本地联调，走 Vite dev server 反代（同源），**本期后端不开 CORS**；将来 H5 需要独立部署给他人访问时，再加
dev-only 的允许来源配置（默认关闭）。

### 1.5 客户端行为（`feat/app-release`）

| 场景 | 行为 |
|------|------|
| APK 启动 | 静默调 `GET /app/version?versionCode={本机 versionCode}`；网络失败、后端不可用都**不提示** |
| 有新版本 | 弹原生 `uni.showModal`：标题带 `latestVersionName`，正文 `releaseNotes`（空则用默认文案），按钮「去下载 / 稍后」 |
| 去下载 | `plus.runtime.openURL(downloadUrl)` 交给系统浏览器，不内置下载器；H5 退化为新窗口 |
| 手动检查 | 「我的 → 关于 → 检查更新」；已最新提示 toast，失败提示检查家庭网络 |
| H5 联调 | 不参与更新（不发请求）：`isAppRuntime()` 无 `plus` 即判定非 APK |

- **弹窗判定以版本号大小为准**：只有 `latestVersionCode > 本机 versionCode` 才提示。不能只看 `upToDate=false` ——
  不传 `versionCode` 时后端恒返回 false（见 §1.1），否则已是最新的用户会被反复打扰。
- **本机 versionCode 来源**：`uni.getSystemInfoSync().appVersionCode`（与 `src/manifest.json` 同口径）；
  versionName / versionCode 的递增规则见 `medbox-app/README.md`「APK 发版」。
